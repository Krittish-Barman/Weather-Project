# 🌦️ Weather Tracking System

The **Weather Tracking System** is a sleek, responsive web application that displays real-time weather information for any location worldwide. Built using **HTML, CSS, and JavaScript**, it integrates the **OpenWeatherMap API** and uses the **Geolocation API** to auto-detect the user's location and display current weather data with a visually engaging interface.
 

## 🔧 Features

- 📍 **Auto-detects user location** using Geolocation API  
- 🔍 **Search weather by city name**
- ⛅ Shows **current weather**: temperature, humidity, wind, and conditions  
- 📆 **5-day forecast** with dynamic weather cards  
- 🎥 **Background video** with gradient overlay for a modern look  
- 🎨 Fully **animated and colorful UI** for enhanced user experience  
- 📱 **Responsive design** for all screen sizes

## 🛠️ Technologies Used

- **HTML** – Semantic structure  
- **CSS** – Styling, gradients, media queries, animations  
- **JavaScript** – Logic and API integration  
- **OpenWeatherMap API** – Weather data provider  
- **Geolocation API** – Location detection

## 🚀 Future Enhancements
